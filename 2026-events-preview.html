📋 How to Add These Events to Your App

Option 1: Quick Import (Easiest)

  1. Go to Firebase Console: console.firebase.google.com
  2. Select your project
  3. Click Realtime Database
  4. Click the ⋮ (three dots) menu on "events" node
  5. Click Import JSON
  6. Upload the 2026-season-events.json file
  7. Click Import
✅ Result: All 9 events added instantly with course images!

Option 2: Add Manually Through App

  1. Log into your app at nobsgolf.co.uk
  2. Go to the Events tab
  3. Click + Add Event
  4. Fill in the details for each event (see event cards above)
  5. Click Save Event
  6. Repeat for all 9 events

Course Images

All course images are in the course-images/ folder. You can:

  • Upload them to your hosting
  • Add them to Firebase Storage
  • Reference them in event descriptions
