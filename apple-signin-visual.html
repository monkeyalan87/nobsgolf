3 Simple Parts

1
Apple Developer Portal

Time: 15 minutes

Create 3 things:

  • App ID - Identifies your app to Apple
  • Services ID - Connects your website
  • Private Key - Lets Firebase talk to Apple

📍 Where: developer.apple.com/account

↓
2
Firebase Console

Time: 5 minutes

Configure Apple provider:

  • Enter your Services ID
  • Add Team ID + Key ID
  • Paste Private Key contents

📍 Where: console.firebase.google.com → Authentication

↓
3
Your App (Already Done!)

Time: 0 minutes

Good news - your app already has:

  • ✅ Apple Sign-In button
  • ✅ JavaScript handler code
  • ✅ Proper styling

Nothing to code! Just test it works.

What You'll Need to Write Down

From Apple Developer

App ID:
com.yourname.nobsgolf

Services ID:
com.yourname.nobsgolf.web

Team ID:
9ABC123XY (10 chars)

Key ID:
ABC123XYZ (10 chars)

Private Key File:
AuthKey_ABC.p8

From Firebase

Project ID:
golf-society-a1b2c

Return URL:
https://golf-society-a1b2c.firebaseapp.com/__/auth/handler

Your Domain

GitHub Pages:
monkeyalan87.github.io

Important: NO https:// when entering in Apple Developer Portal!

⚠️ Common Mistakes:
  • Including "https://" in Web Domain (don't do this!)
  • Wrong return URL (must use .firebaseapp.com, not your domain)
  • Not copying the entire private key (must include BEGIN and END lines)
  • Using same ID for App ID and Services ID (must be different)

Step-by-Step Checklist

Part 1: Apple Developer Portal

Create App ID (Identifiers → + → App IDs)
Enable "Sign in with Apple" capability
Create Services ID (Identifiers → + → Services IDs)
Configure Services ID with domain and return URL
Create Private Key (Keys → +)
Download .p8 file
Note Key ID and Team ID

Part 2: Firebase

Go to Authentication → Sign-in method
Enable Apple provider
Enter Services ID
Add OAuth configuration (Team ID, Key ID, Private Key)
Authorize your domain (Settings → Authorized domains)

Part 3: Test

Go to your website
Click Sign Up → Continue with Apple
Sign in with Apple ID
Verify you're signed into the app
✅ When It Works:

Users will see Apple's sign-in popup, enter their Apple ID, approve access, and get redirected back to your app - all signed in! The entire process takes about 5 seconds for users.
